# Foundation provenance

The canonical `school/**` Foundation slice is original project code.

- Campus geometry is generated from code at runtime.
- The spawn and location registry are generated from original configuration in this repository.
- The SchoolClock and FoundationState implementations are original code in this repository.
- No external map, model, texture, audio, UI, or other non-code asset is mapped by `school/default.project.json`.
- Maze/Pips, Brookhaven projection/parity, RHS-exact/licensed-exact, and other retired runtime trees are not mapped by the canonical project.
